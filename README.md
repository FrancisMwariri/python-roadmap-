# Francis Programming Practice Workspace

This workspace is where you will practice Python and programming ideas from the start.

## Purpose
- Learn Python from scratch
- Practice one concept at a time
- Build small projects and experiments
- Work toward recreating a project like the car game in the main repo

## Your learning approach
This folder is not for saving final game files. It is for learning, experimenting, and testing code.

## Start here
Read the roadmap file first:
- [learning-roadmap.md](./learning-roadmap.md)

## Folder structure
- Each file should focus on one learning topic.
- Use clear names such as:
  - 01_variables.py
  - 02_loops.py
  - 03_functions.py
  - 04_pygame_intro.py

## Goal
By the end of the course, you should be able to explain the code in this repo and rebuild a program like it using your own understanding.

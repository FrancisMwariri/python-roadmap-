# Francis Programming Practice Workspace

This is your personal programming learning workspace. Everything you practice here is meant to build your understanding from zero to the point where you can explain and recreate a project like the car game in the main repo.

## Purpose
- Learn Python from scratch
- Practice one concept at a time
- Build small projects and experiments
- Connect each idea to the real game in this repo
- Work toward creating a complete program on your own

## How to use this folder
This folder is not for final project files. It is for learning, testing, experimenting, and building your confidence.

Use this rule:
- if you do not understand it, write a small example
- if you want to test a concept, make a file here
- if a program works, keep it and explain it in plain English
- if it fails, fix it and learn from the mistake

## What each lesson is preparing you for
- Python basics train you to write logic and solve problems.
- Functions help you break code into reusable pieces.
- Data structures teach you how to store and organize information.
- OOP helps you model real objects like cars and enemies.
- Pygame teaches you how to draw and animate a game.
- Game states teach you how menus, play, pause, and game over work.
- NumPy and AI basics explain the math behind the game AI.
- Computer vision introduces webcam and hand tracking.
- The capstone lesson combines all of it into a full project like the repo.

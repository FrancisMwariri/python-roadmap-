# Francis Programming Learning Roadmap

This folder is your personal programming practice workspace.

## Goal
Build the skills needed to understand and recreate a project like the car game in this repo from scratch.

## Learning path

1. Python basics
   - Variables and values
   - Data types
   - Input and output
   - Math and comparisons
   - Strings and formatting

2. Control flow
   - if / else
   - loops
   - break and continue
   - while loops
   - problem solving with logic

3. Functions
   - Defining functions
   - Parameters and return values
   - Scope
   - Reusable logic

4. Data structures
   - Lists
   - Dictionaries
   - Tuples
   - Sets
   - When to use each one

5. Object-oriented programming
   - Classes
   - Objects
   - Methods
   - Attributes
   - Encapsulation basics

6. Modules and project structure
   - Importing files
   - Organizing code into folders
   - Keeping logic separated
   - Using configuration files

7. Debugging and testing
   - print debugging
   - exceptions
   - assertions
   - basic pytest usage

8. Pygame fundamentals
   - display window
   - game loop
   - events
   - drawing graphics
   - keyboard input

9. Game systems
   - player movement
   - traffic spawning
   - collisions
   - states like menu, playing, game over

10. AI and NumPy basics
    - arrays
    - vectors
    - simple neural-network math
    - fitness and evolution basics

11. Computer vision basics
    - webcam input
    - OpenCV basics
    - hand landmarks
    - gesture recognition

12. Capstone project
    - Rebuild a game like Morning Pursuit step by step
    - Explain each section
    - Practice writing the code yourself

## How to use this folder
- Create one practice file for each topic.
- Keep your code simple and understandable.
- Try to explain each program in plain English.
- Save experiments here even if they are not perfect.
- Ask for feedback when you want help understanding a bug or concept.

## Practice rule
A concept is not learned until you can explain it and use it in a small program.
